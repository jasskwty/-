# 🎓 مساعدي المدرسي

تطبيق ويب يساعد طلاب المدارس الكويتية، من الصف السادس إلى الثاني عشر، في المذاكرة باستخدام Claude.
الواجهة كلها بالعربي (RTL) بخط Tajawal، وفيها وضع داكن، وتشتغل زين على الجوال.

## الأدوات

| الأداة | وش تسوي |
|---|---|
| 💬 اسأل المعلم | محادثة مع معلم خصوصي، الردود تظهر أول بأول، وتقدر ترفع صور |
| 📘 اشرح درس | شرح خطوة بخطوة، أمثلة محلولة، أخطاء شائعة، و٣ أسئلة تدريب |

| 🎯 اختبرني | أسئلة اختيار من متعدد، تحدد عددها وصعوبتها، وتتصحح فوراً مع شرح لكل سؤال |
| 🃏 بطاقات مراجعة | بطاقات تنقلب بحركة، وتتنقل بينها بالأزرار أو الأسهم أو بالسحب |

## 📚 المكتبة ومصادر الوزارة

تبويب **📚 المكتبة** (للطالب) و**📚 مصادر الوزارة** (للمعلم) يجمعون المصادر حسب الصف والمادة والفصل الدراسي:

| المصدر | وش يطلع | كيف ينستخدم |
|---|---|---|
| 🏛️ [مكتبة وزارة التربية الإلكترونية](https://elibrary.moe.edu.kw/StudentsLibrary) | الكتب المدرسية، وأوراق العمل والمراجعات، وفيديوهات الدروس. وللمعلم كمان: **دليل المعلم** و**خطة توزيع المنهج** | تفتح الملف من موقع الوزارة، أو **تختار صفحات** (لين ٢٠ صفحة في المرة) وترسلها للمساعد |
| 🏫 [موقع مدرستي school-kw.com](https://school-kw.com) | فهرس ملفات المعلمين: اختبارات، ومراجعات، وملخصات، وحلول، وبنوك أسئلة، مع فلتر حسب النوع | **روابط فقط**: الملف يفتح في موقعهم |

**استخدام صفحات الكتاب مع المساعد:**
- من تبويب المكتبة: اضغط «📎 صفحات للمساعد»، واختر الصفحات، وبعدها روح لأي أداة (مثل «لخّص» أو «تحضير درس») وبتلقى الصفحات جاهزة تحت زر الرفع.
- أو من داخل أي أداة فيها رفع ملفات: زر **📚 من كتب الوزارة**.
- للمعلم: داخل **مرجع المنهج** تقدر تختار صفحات من **دليل المعلم** أو **خطة التوزيع** وتستخرج منها الأهداف والمعايير.

**ملاحظات:**
- السيرفر يحتاج اتصال إنترنت بـ `elibrary.moe.edu.kw` و `school-kw.com`.
- التطبيق يستخدم نفس الواجهة البرمجية العامة اللي تستخدمها صفحة مكتبة الوزارة. فهرس المكتبات ينحفظ مؤقتاً في ذاكرة السيرفر (لين ٦ ساعات) عشان ما نضغط على المواقع.
- ملفات الوزارة اللي تنختار منها صفحات تنزل مرة وحدة وتنحفظ مؤقتاً (أسبوع) في مجلد النظام المؤقت (`madrasati-moe-cache`).
- ملفات موقع مدرستي من إعداد معلمين وحقوقها لأصحابها، فالتطبيق ما ينزلها ولا يعيد نشرها، بس يربط لصفحاتها. إذا تبي تستخدم ملف منها مع المساعد، نزّله من موقعهم وارفعه بزر 📎.
- إذا غيّر أي موقع شكل صفحاته أو واجهته البرمجية، ممكن يحتاج الربط تحديث في `lib/server/sources/`.

## ▶ العرض التفاعلي (ملف HTML واحد)

تختار **صيغة العرض** قبل التجهيز: **📊 باوربوينت**، أو **💻 كود (HTML تفاعلي)**، أو **الاثنين**. وتقدر تكتب اسم واحد أو أسماء الفريق كلها (مثل «فلان، فلان و فلان»)، فتطلع «إعداد الطلاب» بصيغة الجمع.

أداة البرزنتيشن تطلع العرض بصيغتين:
- **▶ العرض التفاعلي (‎.html‎):** ملف واحد فيه التصميم والحركات والأزرار، وينفتح بأي متصفح.
- **ملف PowerPoint (‎.pptx‎):** مثل قبل.

**شكل العرض التفاعلي:**
- عربي من اليمين لليسار، بخطوط **Alexandria** للعناوين و**Readex Pro** للنصوص، وثيمات منها «كحلي ملكي» (#041E52 و #0149AD).
- عناصر الشريحة تطلع **وحدة وحدة** مع كل ضغطة، ومعها شريط تقدم ورقم الشريحة، وحركات دخول ناعمة، وخلفية متحركة خفيفة.
- **التنقل:** الأسهم، والمسافة، والضغط على الشاشة، والسحب على الجوال، وزرّي التالي والسابق.
- **الاختصارات:** **N** ملاحظات المقدم، **O** كل الشرائح، **F** ملء الشاشة، **Home/End** أول وآخر شريحة.
- بدون إيموجي ولا أصوات.

**أنواع الشرائح:** المساعد يختار نوع كل شريحة حسب المحتوى:

| النوع | وش فيه |
|---|---|
| نقاط | ٣ إلى ٥ نقاط تطلع وحدة وحدة |
| بطاقات | ٣ أو ٤ بطاقات، لكل وحدة عنوان وشرح |
| خطوات | مراحل مرقمة بالترتيب |
| مقارنة | عمودين جنب بعض |
| ميزان تفاعلي | كفتين مثل «ينفعنا / يضرنا»: كل ضغطة تنزّل عنصر في كفته، والميزان يميل |
| أرقام | أرقام مع وصفها (بس إذا الأرقام موجودة في المحتوى) |
| فكرة محورية | جملة أو قاعدة مهمة بخط كبير |
| اختبار تفاعلي | ٣ أسئلة: الصح بالأخضر والخطأ بالأحمر، والنتيجة بالنهاية |
| مؤقت نشاط | ٥ أو ١٠ أو ١٥ دقيقة، فيه تشغيل وإيقاف وإعادة |

**الكود:** في نافذة العرض التفاعلي فيه تبويب **💻 الكود**: تنسخ ملف HTML كامل وتعطيه لأي ذكاء اصطناعي يكمل التعديل عليه، أو تحفظه وتفتحه بالمتصفح.

**الباوربوينت:** كل نوع شريحة يطلع بتصميمه:
- البطاقات مربعات، والخطوات أرقام بدوائر.
- المقارنة والميزان عمودين، لكل عمود عنوان ملوّن.
- الأرقام صناديق كبيرة، والمؤقت وقته بخط كبير.
- الاختبار كل سؤال بشريحة، وبعدها شريحة الإجابات.

والنصوص كلها من اليمين لليسار، حتى السطور اللي فيها كلمات إنجليزية.

**المحتوى:** تقدر تلصق المحتوى أو تضيف صفحات من كتاب الوزارة. إذا أضفت محتوى، المساعد يلتزم فيه بس، وما يضيف معلومات أو أرقام من عنده.

**الأمان:** القالب ثابت ومجرّب داخل التطبيق، والمساعد يعطي المحتوى بس، وأي نص منه ينعرض كنص (`textContent`) وما ينفّذ ككود. والمعاينة داخل التطبيق تشتغل في إطار معزول (`sandbox`). الخطوط تحتاج إنترنت، وبدونها يستخدم خطوط الجهاز.

## 🎯 سلايدات مرتبة حسب الاختبارات (الثانوي)

في أداة البرزنتيشن، لما يكون الصف العاشر أو الحادي عشر أو الثاني عشر، يطلع قسم **🎯 رتّب العرض حسب الاختبارات**:

1. **اختيار ملفات الاختبارات:** التطبيق يعرض ملفات **المراجعات وأوراق العمل** من مكتبة الوزارة للمادة والفصل، ويعلّم القريبة من اسم الدرس. تختار لين ٤ ملفات (لين ٢٠ صفحة من كل ملف)، وتقدر **ترفع اختبارات سابقة** من عندك، مثلاً من صفحة المادة في موقع مدرستي (فيه رابط مباشر لها).
2. **الحصر:** المساعد يقرأ الأسئلة، ويحصر **كل** اللي يخص الدرس (مفاهيم، قوانين، مهارات، أنواع مسائل) مع عدد مرات ظهوره وأنواع أسئلته، ويرتبها بأولوية: 🔴 عالية، 🟠 متوسطة، 🟢 منخفضة. ومعها أسئلة على نمط الاختبار.
3. **قرارك:** تغيّر أولوية أي بند أو تحذفه، وتنسخ الحصر أو تطبعه.
4. **السلايدات:** البنود العالية تاخذ شرائح وتفصيل أكثر، وكل شريحة عليها شارة «⭐ مهم للاختبار» أو «◆ يجي أحياناً»، في المعاينة وفي ملف PowerPoint. وفيه شريحة «🎯 أهم ما يجي بالاختبار» قبل الخاتمة.

التحليل يستخدم الموديل الأقوى (`claude-opus-5-5`)، والحصر ينحفظ مع العرض في السجل.

## 👩‍🏫 وضع المعلم

من الزر **طالب / معلم** في أعلى الصفحة تتحول الواجهة لأدوات المعلم. المبدأ: **المساعد يقترح ← المعلم يراجع ويقرر ← الطالب يتعلم**. التطبيق مساعد للمعلم، مو بديل عنه.

| 🪜 تبسيط المحتوى | نفس النص بعدة مستويات قراءة: مبسط جداً، مستوى الصف، متقدم، أو لغير الناطقين بالعربية. ومعه مفردات وأسئلة فهم |
| 🎞️ برزنتيشن | عرض لشرح الدرس، وفيه ملاحظات للمعلم داخل ملف ‎.pptx‎ |

### ٢. التقييم والاختبارات والتصحيح
| الأداة | وش تسوي |

| 📄 أسئلة واختبارات | ورقة عمل، أو اختبار، أو واجب، أو **بنك أسئلة**. الأسئلة مصنفة بمستوى التفكير (بلوم) ومربوطة بالأهداف والمعايير. فيه أسئلة **تفكير ناقد**، ومفتاح إجابة، وطباعة |

### ٣. التخصيص ودعم الطلاب
| الأداة | وش تسوي |
|---|---|
| 📊 سجل الطلاب | **📷 صوّر الكشف**: صوّر كشف الفصل، أو كشوف كل فصولك مرة وحدة (لين ٨ صور أو PDF)، والمساعد يقرأ الأسماء ويوزعها على الفصول. تراجعها وتعدّلها قبل الإضافة، وتختار لكل كشف: فصل جديد أو دمج مع فصل موجود بدون تكرار. فصول، وطلاب، وتقييمات مرتبطة بمهارات، ورصد درجات. يحسب المعدلات والتحسن والتراجع ومستوى الفصل في كل مهارة، ويصدّر لملف Excel (CSV). **تحليل بالذكاء الاصطناعي** يحدد نقاط القوة والضعف لكل طالب، ويقترح مسارات تعلم ومجموعات، ويكتب **تقارير دورية وتغذية راجعة** لكل طالب |
| 🤝 دعم الاحتياجات | سقالات تعليمية، وتكييفات في المهمة والتقييم، واستراتيجيات للصف حسب الاحتياج: صعوبات التعلم، تشتت الانتباه، طيف التوحد، الموهوبين، وغيرها. مقترحات تربوية، مو تشخيص |

### ٤. الأعمال الإدارية
| الأداة | وش تسوي |
|---|---|
| ✉️ رسائل وتقارير | رسالة لولي الأمر، أو ملاحظة للشهادة، أو تقرير دوري، أو تعزيز، أو تنبيه، بثلاث صيغ |
| 🗓️ المتابعات (داخل سجل الطلاب) | جدولة متابعات لكل طالب أو للفصل، والمتأخرة تطلع بالأحمر |
| 💬 مساعد تربوي | شات عن أفكار الشرح والأنشطة وإدارة الصف |

### ٥. الأمان والخصوصية والتحكم البشري
- **الأسماء ما تطلع من جهازك**: في سجل الطلاب والرسائل، الأسماء تتبدل برموز (S1، S2، [اسم الطالب]) قبل الإرسال، وترجع للعرض عندك فقط. الاستثناء الوحيد: **تصوير الكشف** يرسل صورة الكشف لقراءة الأسماء، وبعد موافقة صريحة من المعلم. المساعد ممنوع ينقل غير الاسم (لا رقم مدني ولا هاتف)، والسيرفر يشيل أي رقم طويل لو وصل بالغلط. تقدر تشوف بنفسك البيانات اللي بتنرسل بزر «👁️ شوف البيانات المرسلة».
- **كل البيانات محلية**: السجلات والنتائج محفوظة في المتصفح فقط (localStorage)، وما فيه قاعدة بيانات أو حسابات. وفيه زر يحذف كل بيانات المعلم من الجهاز.
- **المرفقات والنصوص الحرة تنرسل كما هي** لخدمة Claude، فلا ترفع أوراق فيها أسماء أو أرقام مدنية أو معلومات صحية.
- **كل نتيجة مسودة**: المعلم يقدر **يعدّلها ويعتمدها**، وحالة الاعتماد تنحفظ. التعليمات تمنع المساعد من إصدار أحكام نهائية أو تشخيصات، ومن اختراع رموز معايير مو موجودة في مرجعك.

تحت كل نتيجة فيه زر **نسخ**، وزر **اشرح أكثر** (اسمه **فصّل أكثر** في وضع المعلم)، وزر **🖨️ طباعة** يطبع النتيجة وحدها بدون باقي الصفحة. آخر المحادثات والنتائج تنحفظ في المتصفح (localStorage).

## التشغيل

تحتاج **Node.js 20** أو أحدث.

```bash
cd madrasati
npm install
```

### إضافة مفتاح Claude

1. خذ مفتاح API من [Claude Console](https://platform.claude.com/settings/keys).
2. انسخ الملف `.env.example` وسمّه `.env.local`:

   ```bash
   cp .env.example .env.local
   ```

3. افتح `.env.local` وحط مفتاحك:

   ```
   ANTHROPIC_API_KEY=sk-ant-xxxxxxxx
   ```

المفتاح يُقرأ في السيرفر فقط (داخل `app/api`)، وما يوصل للمتصفح أبداً. ملف `.env.local` موجود في `.gitignore`، فما راح ينرفع على GitHub.

### تشغيل التطبيق

```bash
npm run dev
```

بعدها افتح [http://localhost:3000](http://localhost:3000).

لنسخة الإنتاج: `npm run build` ثم `npm start`.

> لو غيّرت المفتاح وأنت مشغّل التطبيق، وقّف السيرفر وشغّله من جديد.

## الموديلات

- `claude-sonnet-5-5`: الموديل الافتراضي لكل الأدوات.
- `claude-opus-5-5`: للمسائل الصعبة. يشتغل لما تفعّل «مسألة صعبة» في أداة حل الواجب أو «سؤال صعب» في الشات، ولما تختار الصعوبة «صعب» في أداة اختبرني، ودايماً في أداة تصحيح الإجابات للمعلم.
- إذا رفض الموديل طلباً بالغلط، السيرفر يعيد المحاولة تلقائياً على موديل بديل (`fallbacks: "default"`).

تقدر تغيّر الموديلات من `lib/server/claude.ts`.

## هيكل المشروع

```
app/
  page.tsx              الصفحة الرئيسية: اختيار الصف والمادة والتبويبات
  api/chat/route.ts     الشات (بث مباشر + صور)
  api/generate/route.ts أدوات النص للطالب والمعلم، و«اشرح أكثر» (بث مباشر)
  api/json/route.ts     الاختبار، البطاقات، البرزنتيشن (مخرجات JSON منظمة)
components/tools/       واجهة كل أداة (TeacherTools.tsx و TrackerTool.tsx لأدوات المعلم)
components/TeacherPanels.tsx  مرجع المنهج ولوحة الخصوصية
lib/client/privacy.ts   استبدال الأسماء برموز وإرجاعها
lib/server/sources/     الربط مع مكتبة الوزارة (moe.ts) وموقع مدرستي (schoolkw.ts)
app/api/sources/        مسارات فهرس المكتبات واستخراج صفحات الكتب
lib/server/             الاتصال بـ Claude والتعليمات (السيرفر فقط)
lib/client/             البث، الصور، الحفظ المحلي، وملف PowerPoint
```
